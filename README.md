# Social Media Planners v1.0.0
This toolkit automatically analyses your video transcripts (SRT files) and produces a ready-to-use plan

.SYNOPSIS - YTKonji Studio Manager v2.19

    English Metadata Generator (offline, self-contained, niche-configurable)
    VERSION: 2.19
      - Algorithm-optimized titles (no episode numbers, high-stakes curiosity)
      - Punchy 3–4 word thumbnail captions
      - Stronger description + SEO guidance for overlanding audience
      - Updated niche defaults for any niches
      - Async native tools (no FFmpeg deadlock)
      - Write-Progress + WindowTitle progression
      - Format-MetadataBlocks
      - Niche parameters (travel / events / other series)
.DESCRIPTION
    Offline EN pipeline:
    FFmpeg → Faster-Whisper → clean SRT
    → deterministic place-name correction (map-driven)
    → classifier → fact extraction
    → duration-aware chapters + place allow-list sanitize
    → 5 story-driven metadata packages (optimized for YouTube CTR + algorithm)
    → Markdown report
    Defaults match any video series.
    Override -NicheName, -ChannelBlurb, -WhisperInitialPrompt, -PlaceRepairMapPath,
    -RiskyPlaceNames, etc. for other niches without editing the script body.
